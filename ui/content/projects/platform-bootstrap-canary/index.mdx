# Purpose

This internal canary checks the smallest complete managed-project bootstrap.
Its committed profile drives Copier planning, protected HCP Terraform state,
Doppler and GitHub delivery boundaries, and an isolated Cloudflare and Neon
preview. The provider resources are temporary. This operating record and the
profile remain after cleanup so the same proof can run again.

The canary does not hold production data, expose a production route, or add a
second implementation of platform defaults. Its commands and recovery steps
live in `infra/project-modules/examples/minimal-bootstrap/README.md`.
