# Overview

Macrodissection is the selection and removal of tissue for genetic testing. This project aimed to help pathologists find suitable tumor regions faster by highlighting them on digital slide images.

# Workflow

The pipeline read slide images, ran models to identify tumor and dead tissue, and combined their predictions into suggested regions. Pathologists would review these suggestions to guide manual tissue extraction.
