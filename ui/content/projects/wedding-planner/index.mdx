# Wedding planner

This is a place for the wedding decisions that need more than a checklist. It matches guests to beds, rooms and cottages while respecting who is comfortable sharing and working out fair costs. The same guest list and confirmed couples also feed a table planner. A shared music list collects guest requests without handing over the final DJ brief.

Services such as [Joy](https://withjoy.com/) cover wedding websites, guest lists and RSVPs. This project can handle planning gaps alongside a service like that. Later it could become a more personal guest-facing wedding site.

[Open the planner](/wedding-planner)

The private planner stores guests and choices in your browser. Try the sample with fictional guests or import a JSON plan to start, and export a backup if you want to move it to another browser. Accommodation and table choices do not sync between devices. Music suggestions and votes use a separate guest link, while moderation stays in the private planner.

The shared guest model records attendance, invitations, couples and wedding roles independently of sleeping arrangements. Both planners use a domain package, with a repository for saving plans and adapters for browser storage and optimisation. Existing backups migrate when loaded. Guests can be bridesmaids, groomsmen, parents of the bride or groom, and other wedding-party members. Their roles are separate from top-table placement and accommodation payments.

The accommodation planner records shared bed groups and allows individual sharing choices at bed, room and cottage level. Couples can choose separate beds while remaining a couple for table seating. It allocates higher priority guests to the included Riverside suites before cottages. The room plan separates rent already paid, rent still due, guest reimbursements and the couple's final cost.

The table planner fixes the wedding party at the top table and keeps other confirmed couples together. It respects keep-apart rules, maximizes preferred pairs at the same table, then balances table sizes. Guest table counts and individual capacities can change between calculations. Wedding attendance is separate from overnight stays, so day guests can have a seat too.

The music planner groups songs by moments such as arrivals, dinner, first dance and last song. Guests can suggest tracks and vote through a link suitable for the Joy website. The couple can approve, reject, merge and order songs, hide choices, and mark must-play or do-not-play entries. The final brief downloads as CSV or Markdown for the DJ.
