# Wedding planner

This is a place for the wedding decisions that need more than a checklist. It starts with accommodation: matching guests to beds, rooms and cottages while respecting who is comfortable sharing and working out fair costs.

Services such as [Joy](https://withjoy.com/) cover wedding websites, guest lists and RSVPs. This project can handle planning gaps alongside a service like that. Later it could also help with table plans or become a more personal guest-facing wedding site.

[Open the planner](/wedding-planner)

The planner stores guests and choices in your browser. Import a JSON plan to start, and export a backup if you want to move it to another browser. It does not sync between devices.

The accommodation planner models couples as one bed group and allows individual sharing choices at bed, room and cottage level. It allocates higher priority guests to the included Riverside suites before cottages. The room plan separates rent already paid, rent still due, guest reimbursements and the couple's final cost.
