# Data licence and attribution

UK House Price Index source material, adapted index values, and HM Land Registry
Price Paid Data contain public sector information licensed under the
[Open Government Licence v3.0](https://www.nationalarchives.gov.uk/doc/open-government-licence/version/3/).

Retain this attribution with copied or redistributed observations:

> Contains HM Land Registry data © Crown copyright and database right 2026.
> Licensed under the Open Government Licence v3.0.

Price Paid Data uses the attribution published with that dataset:

> Contains HM Land Registry data © Crown copyright and database right 2021.
> This data is licensed under the Open Government Licence v3.0.

Each imported release records its GOV.UK page, download URL, publication date,
retrieval time, SHA-256 checksum, and immutable object key. Keep those fields
with the data. The licence does not cover departmental logos or third-party
material.

Price Paid Data address fields also include Royal Mail and Ordnance Survey
rights. Use them only for residential property price information and keep the
attribution required by the source download page.

The TypeScript code and tests remain under the repository's software licence.
