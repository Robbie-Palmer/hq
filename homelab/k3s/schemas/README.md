# Kubernetes schema catalog

Flux Schema reads this local catalog before the pinned upstream Kubernetes
catalog configured in `../../.fluxschema.yml`.

`doppler-operator-v1.7.1/secrets.doppler.com/dopplersecret_v1alpha1.json` was
generated by Flux Schema 0.12.1 from the Doppler Kubernetes Operator v1.7.1
CRD. That is the same operator release and SHA-256-verified installation
manifest pinned in `../../scripts/install-doppler-operator.sh`.

When upgrading the operator, download and verify its new `recommended.yaml`,
then refresh the schema with the newly pinned Flux Schema version:

```bash
mise exec -- flux-schema extract crd recommended.yaml \
  --strip-description \
  --output-directory k3s/schemas/doppler-operator-vNEW_VERSION
mise run //homelab:k3s-test-remote
```

Review changes to required fields, enum values, defaults, and
`x-kubernetes-validations` rules before committing the generated schema. Keep
the upstream Kubernetes catalog URL at an immutable Flux Schema commit whose
catalog documents the Kubernetes version used by K3s.
